# Running FoodWise RWP in Android Studio

The web app (React/Vite) is wrapped into a real native Android project using
**Capacitor**. This is the standard, reliable way to take a web app to
Android without rewriting it — the Android project is generated by the
`cap` CLI on your machine (this step needs npm registry access, which the
environment that built this project did not have, so it couldn't be
pre-generated for you). It takes about two minutes.

## Prerequisites

- Node.js 18+ and npm
- [Android Studio](https://developer.android.com/studio) installed (includes the Android SDK)

## Steps

```bash
# 1. Install dependencies (includes @capacitor/core, @capacitor/android, @capacitor/cli)
npm install

# 2. Build the web app
npm run build

# 3. Initialize Capacitor (only needed once — capacitor.config.ts is already provided,
#    so you can skip the interactive prompts with these flags)
npx cap init "FoodWise RWP" "com.foodwise.rwp" --web-dir=dist

# 4. Add the Android platform — this generates the real android/ folder
#    (Gradle wrapper, manifest, etc.) that Android Studio opens
npx cap add android

# 5. Copy the built web assets into the Android project
npx cap sync android

# 6. Open it in Android Studio
npx cap open android
```

Android Studio will open the `android/` folder as a normal Gradle project.
Press **Run ▶** to install it on an emulator or a connected device.

## Connecting to the backend from Android

If you want real accounts/database (not just the offline demo mode), run
the FastAPI backend (see `backend/README.md`) on your development machine,
then point the app at it **before running `npm run build`**:

Create a `.env` file in the project root:

```
# Android emulator: 10.0.2.2 is a special alias for your host machine's localhost
VITE_API_BASE_URL=http://10.0.2.2:8000

# Physical device on the same Wi-Fi: use your computer's actual LAN IP instead
# VITE_API_BASE_URL=http://192.168.1.5:8000
```

Then rebuild and re-sync:

```bash
npm run build
npx cap sync android
```

If no backend is reachable, the app automatically falls back to its local
offline demo dataset — it will still fully function on the device either way.

## Re-syncing after any frontend change

Every time you change the React app, repeat steps 2 and 5:

```bash
npm run build
npx cap sync android
```

## Publishing an APK

In Android Studio: **Build → Generate Signed Bundle / APK**, follow the
wizard to create a signing key, and you'll get an installable `.apk` (or
`.aab` for the Play Store) that you can share directly with users.

## Also works as a plain website

None of the above is required to use FoodWise RWP as a website — `npm run
dev` / `npm run build` + any static host (GitHub Pages, Netlify, Vercel)
works on its own. Capacitor only adds the option to package the exact
same app as an Android app.
